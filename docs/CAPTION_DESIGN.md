CAPTION DESIGN – CAPTI

Goal:
Modern short-form video captions inspired by TikTok/Reels/YouTube Shorts.

Core behavior:
- Captions are synchronized word-by-word.
- The currently spoken word is visually emphasized.
- Captions should be highly readable on mobile.
- Text should use bold fonts.
- Captions should support outline/shadow.
- Captions should support configurable colors.
- Captions should support multiple visual styles.
- Captions must remain inside safe screen areas.
